# DioCMS

**Модульная self-hosted CMS собственной разработки на Python / Django.**

Проект разрабатывается; публичный релиз не опубликован.

Сведения о проекте, документация и загрузки — на странице проекта:
<https://gitflic.ru/project/dionis/diocms>

---

## Что это

DioCMS — система управления сайтом, рассчитанная на обычный shared-хостинг
и на собственный сервер. Возможности расширяются модулями: часть модулей
бесплатна, коммерческое распространение остальных оформляется и пока не ведётся.

## Статус

Проект находится в разработке. Публичный релиз и порядок получения дистрибутива
будут опубликованы на странице проекта.
